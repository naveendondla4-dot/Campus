# Campus Buddy 🎓

A daily-use student website built with HTML, CSS and JavaScript.

## Features
- Daily student dashboard
- Today's timetable and weekly timetable
- Assignment tracker with completion status
- Study notes with search
- College notices
- Class polls and voting
- Personal daily task list
- Editable student profile
- Dark mode
- Responsive mobile layout
- LocalStorage persistence (data stays in the browser)

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server or installation is required.

## Important
This is a front-end prototype. Data is stored only in the browser's LocalStorage. For a real college deployment, connect it to a backend/database and add authentication, role-based admin/faculty access, file uploads, and notifications.
